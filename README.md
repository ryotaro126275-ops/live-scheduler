# 🎸 Live Scheduler

軽音サークルのライブ運営を支援する、数理最適化による日割り自動生成Webアプリです。
## Webアプリ（公開デモ）

[![Live Demo](https://img.shields.io/badge/Live%20Demo-Streamlit-FF4B4B?logo=streamlit&logoColor=white)](https://live-scheduler-6zmfqdnsgrseyzexsnvw3c.streamlit.app/)

**[Live Schedulerを使ってみる](https://live-scheduler-6zmfqdnsgrseyzexsnvw3c.streamlit.app/)**

アプリ内で架空のサンプルExcelをダウンロードできるため、データを持っていない方でも日割り生成を体験できます。

### デモの操作方法

1. Webアプリを開く
2. サンプルExcelをダウンロードする
3. ダウンロードしたExcelをアップロードする
4. 出演可能条件を確認する
5. 「日割りを自動生成する」を押す
6. 生成結果・グラフ・検証結果を確認する

※ 初回アクセス時や長期間利用されていない場合は、アプリの起動に時間がかかることがあります。

## 開発背景
多数のバンドの出演可能日・演奏時間・学年構成を考慮する日割り作業の負担を減らすために開発しました。

## 機能
- 開催日・時間・曲数別出演時間の設定
- Excel入力、出演可能条件の確認・CSV保存
- CP-SATによる日割り生成と別プログラムによる検証
- 学年別延べ人数・使用時間の可視化、Excel出力

## 起動方法
Python 3.12 を推奨します。

```sh
python -m pip install -r requirements.txt
python -m streamlit run app_v6.py
```

アプリ内の「入力Excelの形式・サンプル」から架空のExcelを取得し、初期開催条件のままアップロードしてください。確認済みの条件を確認し、日割りを生成します。サンプルは12組です。

入力は先頭シート、1行目は見出し。A列にメンバー名、B列に学年（1〜4）、G列に曲数、H列にバンド名、J〜P列にメンバー名、R列に出演可能日を記載します。出演条件の例：`2026-12-14;2026-12-19@19:00-22:00`（確認表のwindows列）。

## 最適化の仕組み
第1段階で割当バンド数を最大化し、第2段階でその割当数を維持しつつ、開催時間に比例した出演時間と学年別延べ人数の目標からの偏差を最小化します。時間制限内の実行可能解を採用する場合もあり、常に最適性を保証するわけではありません。別の検証処理で全バンドの一意な割当、出演条件、時間容量、時間帯内での配置可能性を確認します。

## 動作実績
Ver.6では実データ102組・合計1,955分の割当と検証に成功しました（開発者のローカル環境）。開催条件変更や容量不足のテストも実施しました。実データは公開していません。

## 制約・今後の展望
出演順の出力、休憩、掛け持ちメンバーの調整は対象外です。未割当が生じる場合があります。公開デモには個人情報を含むデータをアップロードしないでください。
